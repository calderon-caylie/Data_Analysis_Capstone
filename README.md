# Bike Sales Data Analysis Capstone

This project is the final capstone for my Data Technology program. It explores a dataset of 100,000 bike sales records and includes data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard.

## Original dataset:  
https://www.kaggle.com/datasets/jayavarman/bike-sales-data-of-100k


## Project Objectives

This analysis was designed to answer the following business questions:

- How has sales revenue trended over time?
- How do sales trends differ across store locations?
- Can we design a performance metric to evaluate and motivate employee sales performance?


## Tools & Methods

- **Data Cleaning & EDA:** Google Colab (Python)
- Removed null values and duplicate records
- Standardized and transformed fields for analysis
- Created additional calculated columns to support dashboard visuals

- **Analysis Techniques:**
- Trend analysis over time
- Comparative performance analysis by store location
- Employee-level performance benchmarking

- **Visualization:**
- Interactive Power BI dashboard with multiple pages and slicers


## Key Findings

- Overall sales are projected to increase compared to the previous year.
- Certain store locations consistently generate smaller transaction sizes despite similar traffic levels.
- Employee performance varies significantly, with several employees not yet meeting defined sales targets.

These insights can help management refine store-level goals, adjust operational strategies, and improve employee performance tracking.


## Dashboard Overview

The Power BI dashboard includes **four interactive pages**, each focused on a different aspect of sales performance:

- Revenue trends over time
- Store-level performance comparison
- Employee performance tracking
- Sales demographics sorted by year and age
- Interactive filters and slicers for deeper exploration
